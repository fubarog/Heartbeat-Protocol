## 📝 项目简介

这是一个**爱情纪念仓库**，记录了我们从相识、相知到相爱的全过程。我们选择用 GitHub 来保存这份珍贵的记忆，因为：

- **版本控制**：我们的爱情经历了一次次"迭代"，每一次都值得记录
- **开源精神**：爱情是世界上最美好的开源项目，我们愿意分享这份幸福
- **永久存储**：GitHub 的服务器会一直保存我们的故事
