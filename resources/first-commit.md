# name recommend
+ 浪漫诗意风（适合文艺、注重仪式感）
    + Love-Repo （最直白，但很经典）
    + Our-Eternal-Spring （我们的永恒之春）
    + Red-Thread （红线，寓意千里姻缘一线牵）
    + Heartbeat-Protocol （心跳协议，有点极客浪漫）
+ 极客/程序员风（适合技术夫妻，幽默且实用）
    + git-commit-to-marriage （提交到婚姻，寓意“commit”既是代码提交也是承诺）
    + merge-conflict-resolved （解决合并冲突，寓意两人磨合成功）
    + develop-to-master （从副分支到主分支，寓意你是我的唯一主分支）
    + deploy-to-wedding （部署到婚礼，寓意一切准备就绪）
    + love-branch （爱情分支，寓意从主干分出的甜蜜分支）
+ 实用工具风（适合作为婚礼筹备的“数字管家”）
    + Wedding-OS （婚礼操作系统，包含所有模块）
    + Wedding-Plan （婚礼计划）
    + Marriage-Playbook （婚姻手册）
